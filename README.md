# Ximena Aguirre — portfolio

An editorial, fast and accessible portfolio for a senior B2B Marketing & Communications leader working across narrative, PR, field marketing and GTM.

## Local use

```bash
npm run build
npm run check
npm run serve
```

Open `http://localhost:4173`.

## Architecture

- `/` — positioning and proof
- `/work/` — portfolio map
- `/case-studies/` — seven flagship cases
- `/playbooks/` — open-source marketing systems
- `/writing/` — verified public work with role labels
- `/about/` — biography, principles and trajectory
- `/resume/` — ATS-friendly cv with print-to-PDF support
- `/recruiter/` — 90-second recruiter view
- `/proof/` — evidence, attribution and confidentiality notes
- `/contact/` — public contact routes

No framework or third-party runtime is required. GitHub Pages serves the generated files directly.
